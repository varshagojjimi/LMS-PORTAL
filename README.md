## How to Run the Project ?

1. Open the project folder in your code editor (like VS Code).  
2. Open a new terminal.  
3. Run the following command:
4.  python app.py

5. After running, you will see a host link like this:  
    http://127.0.0.1:5000/

6. Press Ctrl + Click on the link.  

7. It will open the LMS Portal in your browser.  



##  About the Project

The LMS Portal helps:
- Teachers to manage courses.  
- Students to view and enroll in courses.  
- Secure login and registration for both roles.



## Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- Database: SQLite / MongoDB (as used in your setup)
